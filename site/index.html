Every vendor reviews your diff

One command sends your changes, a branch or a pull request to each agent CLI you have. They review in parallel and report severity, file:line and the fix.

npx -y consult-mcp@latest review --base main
  • --pr 42 reviews a pull request as GitHub shows it
  • --agents codex,grok picks the advisors
  • Your agent runs the same review with review_changes

Ten tools your agent calls itself

Live sessions, messages and tasks stay off until you turn them on.

ask_agents sends one question to two or more advisors. Their answers come back side by side, so you see where they agree.

ask_session asks a read-only copy of a session you have open. The copy knows its whole conversation; the original keeps working.

send_message leaves up to 4,000 characters for a running session, marked as from a peer agent. Idle Claude Code and Codex sessions wake to read it.

dispatch_task gives a well-defined job to a Codex or Grok worker. Workers are the one exception to read-only, so review their diff.

Advisors can read, not write

Every advisor runs headless, read-only and with no MCP servers. It can’t edit a file or call consult back, so two agents never get stuck asking each other.

Security flags for every advisor

Advisors send the files they read to their own provider, the same as when you use that CLI yourself.

AdvisorHow consult runs it
claude-p --restricted --tools Read,Grep,Glob --strict-mcp-config
codexexec with sandbox_mode="read-only", approval_policy="never", plugins off, every MCP server disabled by name
grok--tools read_file,grep,list_dir, the MCP helper tools disallowed
agy-p, after checking that writes, shell commands and URL fetches need approval, with no MCP servers, plugins or hooks

Copies of live sessions get the same flags, forked with --resume <id> --fork-session (exec fork for Codex).

Instructions that tell agents when to ask

consult ships these lines to the agent that hosts it, so it asks when stuck or before a hard call, not on every turn. Install also adds a short section to each agent’s global instructions file; uninstall removes it.

Set up consult in 3 steps

Needs Node 22 or later and a signed-in claude, codex or grok CLI. Each new session starts the latest release.

  1. 1Register the MCP server

    Adds itself to every agent CLI on your PATH.

    npx -y consult-mcp@latest install

  2. 2Check the agents answer

    npx -y consult-mcp@latest doctor --ask

  3. 3Ask your coding agent

    “Have Grok and Codex review this before I push.”

Runs on macOS, Linux and Windows; live sessions and messages need macOS or Linux. uninstall removes everything it added.
